# Todo App (Vanilla JS)

A minimal todo list web app built with plain HTML, CSS, and JavaScript. No build tools required. Data persists in localStorage.

## Run

- Open `index.html` in any modern browser.

## Features

- Add, complete, edit (inline), and delete tasks
- Filter by All / Active / Completed
- Toggle all, clear completed
- Persists across reloads via `localStorage`
- Accessible: aria-live updates, keyboard friendly

## Files

- `index.html` – Markup and app container
- `styles.css` – Styles
- `app.js` – App logic

## Notes

- Tasks are stored under the key `vanilla_todo_items_v1` in `localStorage`.
- Editing a task: press Enter to save, Esc to cancel.
